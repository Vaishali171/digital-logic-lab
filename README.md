# Digital Logic Lab

A collection of digital logic experiments and simulations built from scratch in C++.

## Current Progress

- [x] AND gate
- [x] OR gate
- [x] NOT gate
- [ ] Truth table generator
- [ ] XOR gate
- [ ] NAND gate
- [ ] NOR gate
- [ ] Half adder
- [ ] Full adder
- [ ] 4-bit ALU
- [ ] Logic circuit simulator

## Goal

Build a small digital logic simulator and gradually understand how
logic gates can be combined to create larger digital systems.

## Tech

- C++
- Digital Logic
- Boolean Algebra
